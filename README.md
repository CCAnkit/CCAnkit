### Featured project

**ChurnX AI** is a multi-tenant churn prediction SaaS and my MSc capstone at DCU. It's live at [churnx-ai.vercel.app](https://churnx-ai.vercel.app/).

Companies upload their customer data or connect their production database. ChurnX returns a churn prediction for each customer and a personalised retention recommendation, with an LLM layer that explains the result.

- 40+ REST APIs documented in Swagger, serving model results in real time
- Model training runs in a Dockerised Python service behind Bull and Redis queues, so it never blocks an API request
- Google OAuth 2.0, JWT role-based access and AES-encrypted database credentials
- CSV and Excel uploads of 100,000+ records are validated and cleaned before ingestion
- GDPR Articles 13 to 20 are built in (audit logging, right to erasure, 7-year automated retention) and tested end to end with Jest and Supertest

> Stack: NestJS 10 · React 19 · Python · Scikit-learn · OpenAI API · PostgreSQL · Redis · Docker
